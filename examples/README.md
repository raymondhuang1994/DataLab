# 合成样例数据

这里的数据由 `generate_samples.py` 使用固定参数/随机种子生成，**不是真实业务数据，不可用于事实判断**。

- `sales.csv`：2025 年 12 个月 × 3 地区 × 3 产品，共 108 条月度汇总记录。`orders` 是订单数；按记录计数不能当作订单数。
- `customers.csv`：300 条虚构客户资料，用于分类流程演示，`churn` 是生成的二元标签。
- `series.csv`：180 个连续日的虚构单变量序列，用于滞后预测/回测演示。

这些样例用于了解输出和验证执行流程，不代表真实数据上的模型效果。

需要重新生成时，运行 `python examples/generate_samples.py --out ../synthetic-samples-001`，输出目录必须尚不存在。生成器不会原地重写这里的样例文件。
