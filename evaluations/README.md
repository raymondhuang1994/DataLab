# DataLab 任务级评测

这套评测区分两种证据，不能把自动脚本得分解释成模型已完成全部自然语言分析任务。

1. `cases.json` 是带实际业务问题、输入数据、明确答案和陷阱的可重复任务集合。`run_benchmarks.py` 实际调用分析/验证工具，依据独立预期答案评分；它测计算和检查行为，不评估自由叙述质量。
2. `agent-tasks/` 是交给独立代理的原始请求和数据。评估代理应只拿请求、数据和 Skill，不拿标准答案；完成后按 `agent-rubric.json` 评审计算、口径、限制、证据与交付。一次成功不能代表所有宿主或模型都成功。

在已准备好依赖的环境、项目根目录执行：

```text
python evaluations/run_benchmarks.py --out ../work/benchmark-run
```

输出目录必须为新目录。结果记录每个任务的通过/失败及原因，保留中间结果便于检查。所有数据是为真实业务问题构造的合成数据，不是客户生产数据。跨平台 CI 会执行同一套计算任务；自然语言代理评测需在实际支持的客户端另行执行并记录。
