# 功能来源与本版范围

DataLab 以 Anthropic `knowledge-work-plugins/data` 的工作流为参考，重新组织为面向 ChatGPT/Codex 的单入口 Skill，并增加可执行的 Python 工具。上游版本及许可证见根目录 NOTICE。

| 工作流 | 上游已有的指导能力 | DataLab 本次实现/扩展 |
|---|---|---|
| 探索与分析 | 数据探索、业务问题分析、统计方法选择 | 文件读取、画像、明确口径汇总、计算表、配置重跑 |
| SQL | SQL 编写、查询优化、方言及连接指导 | 保留工作流，改用当前宿主已授权工具；未附数据库账户 |
| 图表 | 图表选择、Python 可视化、设计与审阅 | 内置 PNG/SVG 图、离线 HTML 报告、中文字体适配 |
| 看板 | 交互式 HTML 看板指导 | 内置筛选/趋势/明细模板；增加本地文件轮询、过期与失败恢复状态 |
| 统计 | 描述统计、检验、回归及分析指导 | 增加 Welch/Mann–Whitney 可执行比较工具与效应说明 |
| 高级建模 | 统计分析中包含回归等方法，非完全空白 | 增加分类/回归候选比较、训练 CV、独立留出、时间顺序评估、单变量预测工具 |
| 验证 | 验证数据、方法、图表和结论 | 增加源指纹、结果 JSON/CSV 一致性、部分指标独立复算及回归测试 |
| 业务上下文 | 提取并维护业务定义和数据上下文 | 保留按需读取的业务词典工作流；不实现跨设备同步 |
| Word | 不属于该 data 插件的专用内置导出流程 | 增加原生 DOCX 正文/表格/图片/分页及可选渲染脚本 |
| 宿主与系统 | Claude 插件目录及工具约定 | 增加标准插件清单、Codex 兼容清单、独立 Skill 包与 Windows/macOS 安装说明 |

本版不含 PPT、跨设备同步、托管部署、后台数据库采集、流式计算平台。高级分析可以由宿主模型依据 Skill 编写额外 Python/SQL；不能把“指导模型完成”标为已有固定工具。

“实时看板”在本版指正在运行的本地 Python 服务定时读取文件变化。静态 HTML 是可交互的数据快照。模型包输出评价数据与复现脚本，不默认序列化可直接部署的模型服务。

## v0.2 新增与兼容变化

- 新增统一指标定义：报告与看板共用聚合、过滤、计数口径；静态前端有同口径计算与对照测试。
- 新增显式项目配置、展示偏好、生效设置及来源记录；不自动扫描个人目录。
- 验证器补独立比例/加权/分组/周期复算及结构化数字声明，整体状态不再自动返回passed。
- 旧脚本请把“检查通过”判断改为 `checks_status == "passed"`，整体 `status` 仍可能是 `needs_review`。
- schema 1.0继续可读；新分析输出schema 1.1。旧自定义分组/趋势表缺标准计算证据时，会明确提示未复算。
- 看板旧count有指标时统一为非空计数；明确需要所有行请用count_rows，需要去重请用count_distinct。
- 实时看板完整源数据在服务端计算；明细上限不截断KPI。离线超过行数上限明确拒绝，避免以局部数据冒充总体。
- 建模算法和预测评估范围沿用v0.1；本轮优先提高口径、检查、评测与可配置性。

## v0.3 文件保护升级

原始数据、配置与历史成果只读；内置输出统一使用任务范围检查和独占创建。分析/建模必须使用新目录，重导出使用新文件名，审计记录输入前后指纹与登记产物。保护通过文件系统目录句柄缩小路径替换风险，但不是限制任意脚本和第三方程序的操作系统沙箱；完整规则见 [READ-ONLY.md](READ-ONLY.md)。
